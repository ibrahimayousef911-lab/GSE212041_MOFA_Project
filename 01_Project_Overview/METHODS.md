# Methods

The analysis is organized into RNA preprocessing/QC, differential expression,
functional enrichment and GSEA, core-signature/PPI analysis, longitudinal RNA
analysis, Olink proteomics QC/differential analysis/enrichment, RNA–protein
matching, MOFA2 preparation/training, MOFA2 downstream analysis, and final
figure/table generation.

The original 27,171-line development script is retained for provenance.
